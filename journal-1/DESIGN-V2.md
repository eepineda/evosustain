# Evoford Journal — Modern Editorial V2

A more contemporary editorial direction built on the existing Journal architecture.

Design principles:
- Editorial first, not SaaS/card first.
- Fluid display typography.
- Strong black/green identity with a warm paper background.
- Asymmetric lead/rail composition.
- Compact utility chrome.
- Large photography with restrained motion.
- High-density desktop grid with deliberate single-column mobile reading.
- Persistent mobile navigation.
- Search as a focused overlay.
- Existing automatic article and author-index workflows remain intact.

The visual language is original to Evoford Journal and is not a copy of any named publication.
