# Publicar en Evoford Journal

Usa `publicar.html` para generar una noticia Markdown. Los campos disponibles incluyen:

- `title`
- `category`
- `date`
- `author`
- `read_time`
- `excerpt`
- `source`
- `image` — URL pública o ruta local
- `image_alt`
- `image_caption`
- `image_credit`
- `slug`

Las fuentes RSS externas se muestran como referencia y enlace al origen; no se copia automáticamente el artículo completo.
