# EvoSustain Journal — Editorial redesign

A high-quality static editorial portal inspired by the principles of premium newspaper design: clear hierarchy, strong typography, strict grids, thin rules, restrained color and content-first layouts.

This is not a copy of any publication's branding, assets or content.

## Responsive
Exactly two layout states:
- Laptop/Desktop: 769px+
- Mobile: 768px and below

There is no separate tablet layout.

## Why this version is sharper
- No spacer `<br>` elements between sections
- Local SVG artwork for crisp images at any screen density
- Newspaper-style front page
- Strong serif headlines and restrained sans-serif utility text
- Thin rules and generous but controlled whitespace
- Dedicated mobile composition
- No external image dependency
- Search and mobile menu
- RSS/GitHub Actions automation retained
