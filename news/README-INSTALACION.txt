EVOFORD NEWS — PAQUETE INICIAL

CONTENIDO
- index.html: portada editorial.
- articles/plantilla-articulo.html: plantilla visual de artículo.
- assets/style.css: estilos adaptables a móvil.
- assets/site.js: fecha de edición.
- feed.xml: estructura inicial RSS.

INSTALACIÓN
1. Descarga y descomprime este paquete.
2. En GitHub abre el repositorio eepineda/evosustain.
3. Entra en la carpeta news.
4. Sustituye o añade los archivos de esta carpeta con los incluidos aquí.
5. Comprueba la vista previa en una rama de pruebas antes de fusionar en main.
6. Cuando GitHub Actions termine, revisa https://evoford.com/news/.

IMPORTANTE
Este paquete es la portada visual inicial y una plantilla de artículo. No incluye todavía
un panel privado funcional, autenticación, aprobación editorial real ni publicación social.
No introduzcas contraseñas, tokens ni claves en archivos públicos del repositorio.
Para el panel editorial habrá que configurar un CMS con autenticación y permisos de GitHub.
El RSS es una estructura inicial; deberá actualizarse automáticamente con cada artículo
publicado antes de anunciarlo como feed completo.

No cambies DNS, CNAME ni los workflows existentes para instalar esta portada.
